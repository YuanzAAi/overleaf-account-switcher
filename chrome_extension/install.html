🚀 Overleaf Account Switcher

Chrome扩展安装指南

重要提示：无感换号功能需要安装此 Chrome 扩展才能使用。扩展连接本地服务与 Chrome 浏览器，负责读取和设置 Overleaf 登录 Cookie。

✨ 功能特点

  • 通过 WebSocket 与本地服务实时通信
  • 支持读取和设置网页脚本无法访问的 httpOnly Cookie
  • 自动重连机制，稳定可靠
  • 完全静默运行，无UI干扰
  • 仅访问Overleaf域名，安全可控
  • 无需重启Chrome，真正无感切换

📦 安装步骤

1

打开Chrome扩展管理页面

在Chrome地址栏输入以下地址并回车：

chrome://extensions/
2

开启开发者模式

在页面右上角找到「开发者模式」开关，将其打开

3

加载扩展

点击左上角的「加载已解压的扩展程序」按钮

4

选择扩展文件夹

在弹出的文件选择对话框中，找到并选择 chrome_extension 文件夹

chrome_extension（内含 manifest.json）
5

确认安装

点击「选择文件夹」按钮，扩展将自动安装

✓

完成！

本地服务运行时，扩展会自动连接。回到桌面程序或 WebUI，可在顶部或「设置运行」查看扩展桥连接状态。

🎯 使用方法

1. 启动程序

启动桌面程序或 Docker 服务，扩展将通过本机端口 9876 自动连接

2. 打开Overleaf

在Chrome中访问 https://www.overleaf.com

3. 无感换号

在「账号管理」选择目标账号，点击「无感换号」

4. 确认切换结果

换号完成后，Overleaf 标签页会自动刷新；如仍显示原账号，可按 F5 再次刷新

❓ 常见问题

Q: 扩展无法连接到本地服务？

请确认桌面程序或 Docker 服务正在运行、端口 9876 可用，并在顶部或「设置运行」查看扩展桥连接状态。

Q: Cookie设置失败？

请检查：
1. 目标账号的Cookie是否有效
2. Chrome是否允许扩展访问Overleaf域名
3. 扩展是否已正确安装并启用

Q: 需要重启Chrome吗？

不需要！这正是使用扩展方案的优势，完全无感切换，无需关闭或重启浏览器。
